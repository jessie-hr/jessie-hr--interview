# Jessie HR 结构化面试助手 V1.0

面向移动端的结构化面试工作台原型，包含今日面试日程、AI 面试辅助入口和题库生成体验。

## 网页预览

项目提供了无需安装第三方依赖的 Web 服务。Codex 会通过 `0.0.0.0:4173` 识别并转发预览端口：

```bash
npm start
```

服务也支持云端平台注入端口，例如 `PORT=8080 npm start`。启动后请使用 Codex 界面提供的
**网页预览 / Open preview（端口 4173）**，不要在自己的手机或电脑上打开
`127.0.0.1:4173`；该地址只代表访问者自己的设备。

健康检查地址为 `/healthz`。

## 当前产品范围

当前版本是 **Jessie HR 结构化面试助手的静态交互原型**，用于体验面试日程、AI 面试辅助入口、
题库入口和移动端界面。它不是完整的 HR 考勤核算工具，暂不包含：

- 员工档案与账号权限；
- 上下班打卡、排班、请假及加班流程；
- 工时统计、薪资或考勤核算；
- 数据库、后端 API 或企业系统集成。

页面中的姓名、日程和岗位均为演示数据，只保存在前端源代码中；应用不会上传或持久化任何输入，
请勿在该原型中填写真实员工信息。本项目未配置 GitHub Pages 或其他公开部署。
